# Phase 1 截图索引

原创 SVG/CSS、虚构内容与合成数据。截图引擎为 Microsoft Edge（Playwright chromium 项目）；另通过 WebKit/iPhone 13 流程与布局检查。

共 72 张 PNG。桌面截取整页，手机截取 390×844 视口以保留真实固定底栏位置。
