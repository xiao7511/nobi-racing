# 新闻翻译、首页图片轮播与双向滑动 · 2026-11-08

## 新闻翻译

根因包括：整批后台翻译占用同一队列、已完成标题等整批结束才发布、较早的 HTTP 补查覆盖 SSE 新译文，以及来源语言识别和赛车术语误判。另有实际提供方限制：当前本地模型只支持英文转中文，其他语种仍依赖配额有限的后备服务。

- 当前阅读文章的翻译请求优先于下一批后台标题；推理请求仍串行执行，不并发争用本地模型。
- 每批完成后立即更新标题、写入缓存并推送页面；已完成的中文不会被失败刷新清空。
- 缓存中的中文和本站校订标题立即显示，无需等待后台队列；修正西语、葡语、德语等来源被误送入英文模型的问题。
- 补充赛车动力单元、品牌译名和出版者尾缀处理，保留人物、数字、否定词及赛车术语的质量检查。
- 详情在 4、6、10、15、20 秒间隔提前复查，保留已显示内容；五次仍未完成则停止自动重试，保留手动重试。已确认失败用“暂不可用”，仅仍在工作的任务用“处理中”。失败不作永久缓存，后续服务恢复可重试。

本次不是新增付费翻译服务或本地多语种模型。来源不可读、模型无法给出可用译文、后备配额耗尽的内容仍可能暂不可用，不将占位说明冒充译文。

## 首页新闻图片轮播

“最新分站战报”的背景读取官方最新图片新闻，按当前已开始的分站名称、来源日期和真实新闻内容匹配，最多三张，每六秒轮播。图片及标题进入对应站内新闻详情；支持上一张、下一张、圆点和暂停。

页面隐藏、焦点进入、悬停或用户选择减少动态效果时暂停自动切换。没有匹配图片或图片失效时保留原资料背景。博彩推广不会进入新闻图片轮播。

## 全站左右切换

左滑到下一栏目，右滑到上一栏目：

首页 → 资讯 → 新闻 → 赛事 → 数据 → 我的 → 论坛 → 设置 → 来源 → 隐私版权 → 首页。

新闻、赛事、车手等详情优先使用实际历史记录，否则回到所属栏目，不生成不存在的详情 ID。另提供中英双语上一页／下一页按钮。纵向滚动、缩放、文字选择、表单、视频、图表、图片轮播和横向滚动区域不触发页面切换，移动底栏仍为五项、64px。
