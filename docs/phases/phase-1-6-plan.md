# Phase 1–6 任务分解（仅计划）

本文不授权或启动后续开发。Phase 0 结束后，先补齐其环境受限的验证并由用户明确选择进入下一阶段。各 Phase 均交付独立报告、可审查分支、迁移与测试证据；不自动购买数据服务或部署生产。

## 总体依赖

Phase 0 补验 -> Phase 1 身份与基础纵切 -> Phase 2 赛历/资讯/管理 -> Phase 3 数据适配与统计 -> Phase 4 移动端和提醒 -> Phase 5 可选 AI/社区 -> Phase 6 发布候选与运维。Phase 5 的 AI 与社区可分别延后，不能阻塞已获权的核心资讯能力。

每阶段完成条件：验收场景演示、对应自动化测试通过、迁移 validate、权限负向测试、双语与 Mock 标记检查、风险表更新。仅绿色基线静态检查不代表业务验收通过。

## 不确定项与变更规则

五大导航补入“首页”为Phase 0假设；赛事系列范围、实际供应商、独立管理域名、IdP、App ID、通知/模型账号、用户地域与SLO由对应阶段确认。任何范围变更先更新契约、迁移、权利清单、风险登记和验收场景，不直接扩散到实现。

估算在工具链与数据许可确认后按上述任务给出，不用未经证实的供应商接入时间承诺发布日期。每阶段入口未满足时可继续文档/Mock验证，但必须标明真实链路未验收。
