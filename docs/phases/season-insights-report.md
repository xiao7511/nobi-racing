# 用数字，读懂赛季

日期：2026-11-01。完善车迷端 `/stats`，本轮仅更新本机开发预览，未公开部署。

## 功能

- 默认后端模式下，统计页改为 OpenF1 的 2026 已结束正赛积分参考，移除该页旧合成积分表及其赛季／积分数据库请求。原 UUID 车手、车队与成绩详情 API 保留，其他页面的合成来源标记不变。
- 车手与车队榜单切换，按已收录正赛回看，所选类型与场次保存在 URL。最新快照截至奥斯汀，当前收录 18 场、23 位积分榜车手及 11 支车队；仍有积分的替补车手不会因缺席最新场次而丢失。
- 展示榜首积分、领先分差、本站正赛最高得分、可回看场次；提供双车手／双车队累计积分走势图、对比卡片和可展开的逐站数值表。曲线缺失点不补零、不跨缺失记录连线。
- 榜单支持中文／英文姓名、车队及车号搜索，按名次、积分或正赛得分排序。保留来源名次及同分排序，积分差通过整数千分位计算，避免十进制浮点误差。
- 中英双语、深浅主题及移动端布局。本站正赛得分与赛季累计积分有明确口径，前者不含冲刺赛。本站正赛前后排名箭头不冒充上一站前后的变动。
- 失效、禁用、错误和不存在的场次均不展示替代数字。有效期到达后隐藏统计，离线清除页面数据；恢复联网重新读取。

## 数据与来源

新增 `GET /api/v1/season-insights`，固定读取 OpenF1 的 2026 Race 会话及 `championship_drivers`、`championship_teams`、`drivers`。仅选结束至少 30 分钟的明确场次 ID，避免调整场地后 ID 不按日期排列造成遗漏或读取未来场次。积分源暂缺的历史场次不伪造记录；最新已结束正赛缺少任一榜单时整份快照不可用。

每小时由后台同步，四次有界 JSON 请求，六小时原子快照；失败清空并十五分钟后允许重试。访客读取不触发上游请求。与赛历共用限速器，最多每秒两次开始请求。历史车手资料按明确已结束场次获取，优先对应当站所属车队，不把最新车队关系套到历史场次；缺少当站归属时明确提示。来源照片字段未用于页面或转存图片。

[OpenF1 文档](https://openf1.org/docs/)将积分接口标为 beta；[来源使用说明](https://openf1.org/)列明历史访问及个人非商业用途。页面、响应与版权来源页保留 OpenF1、CC BY-NC-SA 4.0 和中文整理／图表适配说明。数据适配沿用该许可，不据此声称取得公开商业运营授权或官方最终成绩认证。

配置为 `nobi.season-insights.mode` / `SEASON_INSIGHTS_MODE`：通用部署默认 `disabled`，local profile 默认 `personal`。启用个人模式还要求服务绑定 `127.0.0.1` 或 `::1`。当前独立 Java 预览端口 5290 显式启用 personal，车迷预览端口 5279。不是实时计时服务，不使用付费实时凭据。

## 验证

证据位于 `docs/verification/season-insights/`：

- 前端 lint、类型、3 项 Node 基线、46 项 Vitest 和双应用构建通过。
- Java `mvn verify`：34 项单元测试通过，包括新增六项历史场次边界、积分与身份校验、历史车队、原子失效、禁用与请求次数测试。
- Edge／移动 WebKit 共 12 项浏览器用例通过，包含新积分回看、精确分差、中文搜索、对比、来源失效及既有资讯／赛历回归。
- `scripts/verify-season-insights-live.mjs` 使用实际 Java API，无浏览器 API 替身；两种设备 × 两种语言 × 两种主题共八种组合通过，保存 16 张车手／车队截图。验证 18 场历史、23／11 项榜单、对比、搜索、离线恢复、无页面横向溢出，无第三方资源请求或旧合成积分请求。
- OpenAPI 及生成类型漂移检查通过。API 校验保留既有 readiness 缺少 4xx 声明的一条警告。
- 原 Phase 3 合成数据库浏览器用例改为从 API 取得 ID 后进入车手／车队详情，不再依赖统计页上的合成榜单入口。未重跑完整 PostgreSQL／Redis 回归，未据此声明完整数据库验收。
