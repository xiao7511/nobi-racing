# 新闻正文、触摸操作与车迷聊天

2026-11-03。此前第三方新闻“站内查看”展示通用索引说明，本次为已核对的七组事件（八个索引链接）加入原创双语简报，包含具体事件、结果和背景。以事实来源链接供读者自愿核对，不转载发布者完整文章；未独立确认的财务传闻明确标注。未准备正文的新条目不再提供空的阅读按钮。简报使用稳定 URL 哈希，索引滚动过期后原链接仍可阅读。索引抓取和正文核验是不同流程，新条目正文不会因抓取成功而自动声称已核实。

触摸使用 `touch-action: manipulation` 取消双击放大，保留双指缩放。Web/Android 单指向右滑动返回应用历史；直达详情有父级回退。纵向滚动、输入、按钮、视频、横向相册、多指操作不触发返回。iOS 使用 WKWebView 原生边缘返回，避免重复识别。桌面模拟和 WebKit 触摸测试不能替代实体 iPhone 的安装验收。

论坛改为主题内聊天气泡，支持 Unicode 表情、六张本站原创 SVG 贴纸、引用消息、回复提醒、未读角标、逐批加载最近 200 条消息，以及主页和“我的”入口。页面可见时每八秒刷新讨论，站内提醒另每二十秒更新；不使用系统推送。消息仍须人工审核后公开，待审仅作者和管理员可见；不默认发布测试内容。

SQLite 仅增加列、表与索引，保留原用户、帖子和会话。引用消息必须属于同一已公开主题；提醒只向主题作者和被引用消息作者发送，排除发送者并防止重复审核产生重复提醒。读取和标记已读均按收件人限制；举报、删除或隐藏主题后通知不暴露内容。提醒保留 90 天，注销通过外键删除相关内容。凭证仍仅保存在页面内存。

验收证据在 `docs/verification/community-gestures/`。本机 WebKit 390px 完成注册、贴纸、审核、引用回复、未读/已读和注销完整流程；320px 和 Edge 桌面验证正文语言切换、入口、手势与无横向溢出。测试只写入隔离本机数据库，并在结束时注销用户。52 个前端单测、13 个公开服务测试和 3 个基线测试通过，包括旧论坛数据库迁移保留和跨用户消息权限。
