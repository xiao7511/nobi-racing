# 多渠道新闻与移动端交互更新

2026-11-04。

新闻扩容使用 GDELT 允许公开使用的元数据，增加新文章清单及流式归档恢复，并保留英文、多语种知识图谱。它们覆盖多家发布者，抓取与重试独立；开放赛历另来自 When’s the Race（CC BY 4.0，署名 F1DB、sportstimes/f1）。不直接接入要求另行取得公开分发许可的出版者 RSS，不复制发布者图片或新闻全文。

GKG 过去按稀疏时间片补抓且只追近两小时，改为跟踪连续缺失批次，恢复过去 24 小时。GAL 按已验证的每刻钟后首分钟归档进行保底补抓，并持续轮询滚动文章清单；标题、URL、采集时间之外的描述、配图与标志被丢弃。批次须实际成功读取才记录成功时间，缺失文件不能伪装更新。归档 gzip 流有压缩/展开/行长度限制。非文章的作者页、分类页等会排除，重复 URL 保留较早的发现时间。

中文版默认显示全部语种，不再隐藏待译外文新闻。提供来源筛选、数量和逐通道状态，筛选面板默认收起，最新媒体动态排在战报前。近期元数据标题已整理为中文，另增加哈斯车手调整、本田散热问题、赫塔巴西站练习和安东内利塞纳家族访问四组原创双语简报，以公开团队公告和核实过的报道事实为依据，非全文翻译转载。未知正文仍不提供空的阅读按钮。

返回改用 SPA 内交叠过渡及短距离触摸反馈，停用 iOS 原生 WKWebView 历史快照手势。公共数据仅在内存暂存两分钟，返回立即重绘并重新请求，过期数据不恢复，论坛不进入此缓存。组件离开时保持可见内容到过渡完成，避免先清空再取数。减少动态效果偏好仍受尊重；没有禁用双指缩放。

论坛列表可展开帖子下方回复，直接发送文字、表情和原创贴纸，支持引用、查看最近回复、进入完整讨论和举报。只展开的主题轮询回复，待审可见范围、通知及账号权限保持原服务规则，公开网站不写入验收账号或帖子。

安卓读取 Capacitor SystemBars 注入的安全区变量，兼容系统 `env()` 回退，统一页头、底栏、横向缺口及内容间距。导航改用固定 24px SVG 图标，短屏横向也保持五项底栏；键盘打开时隐藏底栏以避免挤压输入区域。帖子输入工具按栅格排列，避免表情孤立换行。

验收证据位于 `docs/verification/news-expansion/`。浏览器 Android 用户代理和安全区注入用于布局回归，不等同于实体 Android 或 iPhone 安装验收。

54 个前端单测、18 个公开服务测试及 3 个基线测试通过。Android 360px 预览覆盖首页、资讯、赛事、统计、个人页、设置，验证无横向溢出；915px 横屏验证五项底栏保持同一行。WebKit 390px 与 Android 360px 连续帧核验返回期间内容始终可见、首帧恢复已加载新闻；键盘场景核验底栏隐藏及恢复。论坛直接回复、引用、贴纸、审核可见范围、通知和举报入口使用隔离账号验证，测试后删除。

部署还保留过去 48 小时生成的不可变静态资产，防止用户已打开的旧网页在返回或切换栏目时，因旧懒加载代码块被删除而得到 404。仅复制自有上一版本目录内的普通文件，不覆盖新版本文件。
