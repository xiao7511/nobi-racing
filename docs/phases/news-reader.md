# 新闻导航、站内阅读与本地视频 · 2026-11-03

## 已实现的范围

- 底部新增独立“新闻”菜单，进入 `/newsroom`；现在为首页、资讯、新闻、赛事、我的五项。保留 64px 加安全区的固定高度和五列等宽；新闻详情归属“新闻”，不再同时选中“资讯”。
- 新闻列表标题和主要操作进入站内 `/newsroom/:id`，不自动打开发布者网站。新提供结构化开放赛果生成的本站报道，正文、积分资料和来源说明随中英文切换；赛季累计积分与比赛分类明确区分，保留 F1DB / Marcel Overdijk 与 CC BY 4.0 署名。标题翻译扩展为中英双向，共用原有每日 4000 字符和每轮 4 次请求上限。
- 第三方新闻索引没有正文转载授权，站内详情明确为索引说明及独立资料，不是原文全文或全文翻译。原站链接保留在资料来源区，仅为可选项。**“所有第三方原文全文自动翻译”未启用，需要能允许公开译载的全文源或相应许可。** 不能把当前 GDELT 元数据许可扩大解释为出版者全文许可，也不将原创战报或索引说明冒充原文。

## 视频调查及改动

- YouTube 在中国大陆通常不可直接访问，更换界面播放器不能改变媒体源网络限制；此外前版还实测了平台嵌入与版权限制。[网络可访问性背景](https://freedomhouse.org/sr/node/7139)。
- 核查了 [哔哩哔哩官方站外播放器文档](https://player.bilibili.com/)。真实官方公开视频分享条目虽能取得，测试播放器却返回错误视频，正常页面或元数据也出现 412，因此没有将它宣传为已经可用，也未绕过访问限制或提取私有播放地址。
- 改用本站提供的真实资料视频与 HTML5 原生播放器，无 iframe、第三方播放器 SDK、站外播放跳转或 YouTube 网络请求。视频点击播放，支持原生播放控制、全屏及移动端内联播放。
- 三段来源明确为 CC BY-SA 4.0 的完整资料片：2026 澳大利亚站达蒙·希尔、2026 澳大利亚站角田裕毅、2021 俄罗斯站暖胎圈发车。真实拍摄日期、原作者与许可均显示；不是 2026 墨西哥站集锦或直播，不伪装成最新分站画面。
- 用隔离的 FFmpeg 工具将 WebM 完整转为 H.264/AAC MP4，最大 1280×720，保留原声音和完整时长；衍生视频继续 CC BY-SA 4.0。署名、源文件、改动与 SHA-256 位于 `apps/fan/src/content/newsroom-videos.json` 和公开 `media/videos/LICENSES.json`。没有抓取或重传 YouTube/B站的版权视频。
- 旧 `/media/news-player.html` 返回 410；主站 CSP 禁止嵌入框架，只允许本站媒体。新闻正文使用纯文本渲染，不注入来源 HTML。

## 验收

浏览器检查需验证播放时间确实推进、媒体无解码错误、无外站请求与弹窗；仅检查 `<video>` 或 iframe 存在不能作为播放成功证据。站内阅读需检查中英正文、可选来源链接、未授权内容提示、五项菜单及手机视口稳定。证据存于 `docs/verification/news-reader/`。

本机 Edge 桌面、WebKit 320/390px 均完成三段视频的实际播放，媒体无解码错误、播放时间推进，所有 HTTP 请求来自本站，没有新窗口。检查中英正文切换和新闻详情归属，手机视口 scale=1、底栏高度 64px。切换视频复用媒体元素；离开视频分页或页面时显式暂停并卸载媒体，避免残留解码和网络资源。浏览器产生的同源 `blob:` 媒体缓冲不计为外站网络请求，CSP 允许该缓冲用途。

最终 lint、类型检查/前端构建、3 个基线测试、49 个前端单元测试、11 个公开服务测试通过。受本机内存约束，浏览器、构建与单元测试串行执行；前端单测使用一个工作进程。没有关闭其他项目或用户应用。
