# 简体中文资讯与赛事周末信息

日期：2026-11-01。用户要求简体中文资讯标题及内容中文化，并补齐各周末赛事资讯栏。本轮继续本机个人、非商业预览，不公开发布网站。

## 页面变化

- 资讯及首页预览在简体中文模式下显示中文标题和来源 RSS 短摘要。英语模式保持原文；中文模式可展开原始标题、摘要并前往发布方。明确区分“本机机器翻译”和“AI 辅助中文校订”，标注短摘要不是新闻全文。无法翻译时显示中文提示，不把英文默认为已翻译内容。
- 新资讯可由本机 Argos en-zh 1.9 + CTranslate2 离线翻译，OpenCC 转为简体。没有调用外部翻译 API，没有购买服务或获取其他应用的凭据。当前二十条内容另作了 AI 辅助中文校订，改善专名及赛车术语。校订以原文 URL、标题、摘要的 SHA-256 绑定，内容变化即不匹配；校订库不创建新闻、不在源失效时充当缓存或样例。中文校订不是发布方译文，也不是独立事实核查。
- 开放基础资料的三个条目增加简体中文名称及整理说明，避免把繁体条目或英语描述直接显示为简体正文。
- `/races` 优先展示 OpenF1 的真实 2026 周末参考，包含赛事名、来源提供的赛道简称/举办地、周末起止、常规/冲刺会话、逐场开始及结束时间、取消状态、当前与后续/全部/已结束/取消筛选，并支持用户时区与来源赛道 UTC 偏移切换。
- `/weekends/{meeting_key}` 提供周末详情和展开的完整会话安排。每张周末卡片按赛事词及周末前七日至后三日匹配来源报道，最多三条，显示中文标题及摘要。没有匹配报道或缺少日期时不伪造关联。开发合成赛历折叠到明确的 MOCK 区域；原 UUID 比赛及成绩 API 保留。

本轮真实 OpenF1 响应有 25 个大奖赛周末记录，其中 2 个已取消、23 个未取消；测试周末不纳入大奖赛列表。当前及未来默认展示 5 个周末。本轮源资料包含调整后的赛事名称和举办地，以 API 当时字段为参考，不冒充官方最终安排或实时成绩。取消场次没有来源会话时保持空安排。

## 来源、范围与运行

新 `GET /api/v1/weekends` 固定读取 OpenF1 2026 meetings/sessions 两个端点，六小时原子内存快照；失败移除展示结果，十五分钟后允许再试。不抓取实时遥测、不绕过实时付费或认证。结构、年份、ID 唯一性、时间顺序及会话与周末边界均校验；响应上限沿用有界 HTTP 下载。前端也校验来源、许可、有效期及内容结构。

[OpenF1](https://openf1.org/)说明个人学习和非商业车迷用途，网站标注 CC BY-NC-SA 4.0；[API 文档](https://openf1.org/docs/)说明未来周末及会话数据。页面及 API 均保留来源和许可，本站整理的中文字段及数据适配按同一数据许可提供，不因此改变项目软件代码许可。网站及源码本次没有公开发布。

BBC 资讯仍限既有本机个人阅读场景。用户本轮明确要求中文阅读，由本站提供翻译辅助，保留原文，未把翻译解释为发布方授予的商业改编或再分发权。公开/商业使用前仍须核实[来源现行条款](https://www.bbc.co.uk/usingthebbc/terms-of-use/#15metadataandrssfeeds)，必要时更换允许相应用途的来源。

运行配置：`NEWS_TRANSLATION_ENABLED=true`、`WEEKENDS_MODE=personal`；通用部署分别默认 false / disabled，local profile 默认启用。周末源仅在 loopback 监听且 personal 模式下运行。离线翻译位于 `127.0.0.1:5291`，启动/停止与安装见 [翻译运行说明](../../services/local-translation/README.md)。模型 SHA-256 已核验；模型、依赖及原始下载位于忽略的 `.tools/`、`.cache/`，没有提交大模型文件。

预览仍为 `http://127.0.0.1:5279/#/news` 与 `/#/races`，API 5290。原积分/合成数据库读取在本轮独立预览未配置数据库凭据，因此不以其错误状态代表真实赛事缺失。新周末参考独立可用。

## 验证与证据

`docs/verification/chinese-weekends/` 保存最终证据：

- 前端 lint、类型、3 项 Node 基线、40 项 Vitest 和双应用构建通过。
- 28 项 Java 单元测试通过，包括新增周末取消/来源会话/中文名称、原子过期/失败、重复 ID 与时间错误、禁用模式不发请求。
- 桌面 Edge 与移动 WebKit 共 8 项隔离浏览器用例通过，覆盖中文资讯显示、原文链接、搜索、过期、失败状态、周末中文会话、详情返回、取消筛选和时区切换。
- `node scripts/verify-chinese-weekends.mjs` 在真实 Java RSS、离线翻译及 OpenF1 链路上完成桌面/移动验证，无浏览器 API 替身：20 条中文资讯、25 个周末记录、2 个取消场次、匹配报道和详情时区均通过。截图见 `news-*.png`、`weekends-*.png`、`weekend-detail-*.png`。
- OpenAPI 校验及生成漂移通过；仍保留既有 readiness 缺少 4xx 声明的一条警告。Python 翻译服务编译检查通过。未重跑完整 PostgreSQL/Redis Phase 3 回归，原后端浏览器会话测试仅为新的折叠样例区域补上展开操作，未据此声称全量验收。

语言模型仍可能对新报道产生不准确译文；保留对照原文，译文有明确标记。此交付不代表数据提供者背书、生产公开运营或整体法律合规认证。
