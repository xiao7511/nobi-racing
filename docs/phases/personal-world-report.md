# 你的赛车世界

日期：2026-11-01。本轮完善 `/profile` 的本机个人中心。

- 真实车手、车队、赛事周末关注，以及 BBC 原文链接书签；积分榜、周末卡片与资讯列表均有可切换的关注／收藏按钮。个人中心可直接添加、取消关注和移除书签，按四种类型筛选，并显示数量。
- 根据有效来源显示所关注车手／车队的最新积分与截至场次，赛事日期按用户时区显示。接下来关注的周末及下一场会话以来源赛程为准，不充当推送或实时直播提示。查看积分链接带搜索条件，返回对应榜单条目。
- 只持久化偏好、关注标识与经过验证的原文 URL。去除 RSS 跟踪参数后去重，不缓存标题、正文或积分快照。来源到期、离线、禁用或失败时移除相关事实，选择和可移除的原文链接继续保留。
- 每类最多 100 项，错误标识及不安全 URL 被拒绝；容量限制和存储不可用会明确提示。设置中的清空操作覆盖所有关注和书签，保留语言、主题和时区。
- 保留旧 UUID／原创样例选择，只有存在旧选择时才加载对应数据并明确标注样例，不向默认个人中心混入示例关注。无旧关注时不请求原合成数据库目录。
- 中英双语、深浅主题及手机布局；来源与隐私说明同步更新。不创建账户、云同步、通知权限或分析追踪。

验证证据位于 `docs/verification/personal-world/`：前端 lint、类型、3 项 Node 基线、49 项 Vitest 和双应用构建通过；Edge／WebKit 共 18 项浏览器用例通过，包含跨页关注与收藏、刷新持久化、清空数据、来源失效和存储失败。真实 Java API 的两种设备 × 两种语言 × 两种主题共八种组合通过；检查书签与关注操作、重载、离线清除与恢复、无横向页面溢出、无第三方页面资源请求及无旧合成目录请求。保存八张完整个人中心和两张空态截图。

实际联调曾遇到 Java 直接连接 BBC 超时，采用开发机已有系统代理后恢复。独立预览启动 Java 时需在 `-jar` 前使用 `-Djava.net.useSystemProxies=true`；原 `scripts/local-phase2.ps1` 已包含此参数。未改变生产网络策略。复验时 BBC 接口返回 ready 和 20 条来源资讯。

本轮没有后端业务、数据库或 API 契约变更，未重跑 Java／PostgreSQL／Redis 完整回归。此报告记录本机交付；后续公开服务器和移动端分发须另行完成部署验证。
